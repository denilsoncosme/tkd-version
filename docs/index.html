Sobre o aplicativo

O Score Fight LAN foi desenvolvido para auxiliar árbitros, técnicos e organizadores durante combates de Taekwondo.

O aplicativo permite controlar a pontuação e o tempo do combate através de uma conexão de rede local, proporcionando uma alternativa simples para utilização durante treinamentos e competições.

Principais recursos

  • Controle de pontuação do combate
  • Controle do tempo das rodadas
  • Configuração de intervalos
  • Comunicação entre dispositivos pela rede local
  • Interface otimizada para utilização durante o combate
  • Feedback visual e vibração

Suporte
